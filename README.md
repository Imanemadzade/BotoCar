# BotoCar 🚗

A simple car selling website simulation built with Next.js, focusing on price filtering and clean UI structure.

## 🧠 Project Idea
This project simulates a **car marketplace website** where users can filter cars based on price.
The main goal is to practice:
- Component-based development
- State management for filtering
- Clean and readable code structure

## 🛠️ Tech Stack
- Next.js
- React
- JavaScript (ES6+)
- CSS

## ✨ Features
- Car listing UI
- Price-based filtering
- Reusable components
- Simple and clean layout

## 🚀 How to Run Locally
1. Clone the repository  
   `git clone https://github.com/Imanemadzade/BotoCar-.git`

2. Install dependencies  
   `npm install`

3. Start the development server  
   `npm run dev`

4. Open your browser and go to  
   http://localhost:3000

## 📌 Notes
This project is built for learning purposes and to demonstrate front-end fundamentals using React and Next.js.
